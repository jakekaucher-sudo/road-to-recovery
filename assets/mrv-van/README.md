# SBA Disaster Recovery MRV van — views

Vector (SVG, 2000 × 1339, white background) views of the Mobile Recovery Vehicle, matched to the supplied driver-side reference.

| File | View |
|---|---|
| `mrv-van-02-passenger-side.svg` | Passenger side (livery mirrored, text reads normally) |
| `mrv-van-03-front.svg` | Front |
| `mrv-van-04-rear.svg` | Rear (doors carry the SBA logo and DISASTER RECOVERY lockup) |
| `mrv-van-05-front-three-quarter.svg` | Front three-quarter from the passenger side |
| `mrv-van-01-driver-side-check.svg` | Rebuild of the reference, for comparison only |

`build_views.py` generates all five. Edit it and run `python3 build_views.py` to regenerate.

## Colors (sampled from the reference)

- Navy `#1C3E75`
- Red `#CD2127`
- White `#FFFFFF`
- Rocker gray `#4A4E51`, bumper `#2D3339`, outline `#0C0D16`
- Glass `#E0E2E6`, amber marker `#F58321`, hub `#C9CBD0`

## Text

Set in Source Sans 3 / Source Sans Pro, falling back to Helvetica/Arial. If the exact font matters, install Source Sans 3 or convert the text to outlines in Illustrator.
